# 备考台 · 本地查题 + 刷题 + 官方原文依据

备考用的小站：粘一道题给答案，还给**官方原文依据**；题库能逐题刷、判对错、记错题。
全部跑在本机（127.0.0.1），不上传任何东西，只读本地文件。

---

## 启动（三种方式，选一种）

| 方式 | 怎么做 | 适合 |
|---|---|---|
| **双击**（推荐） | Finder 里双击 `查题.command` | 不敲命令；开一个终端窗口 + 自动开浏览器 |
| 命令行 | `cd exam-lookup && python3 webui.py` | 想看日志 / 指定端口 |
| 指定端口 | `python3 webui.py --port 9000` | 默认端口段被占 |

- 打开地址：`http://127.0.0.1:8765/`（被占自动顺延 **8765→8769**，不会有报错弹窗）
- **停**：关掉那个终端窗口，或在该窗口按 `Ctrl+C`（`查题.command` 的窗口一关，服务就停）
- 这是**前台进程**，不常驻：合上终端/重启电脑就没了，再双击一次即可
- 改了 `ask.html`（样式/文案）**不用重启**，浏览器刷新就行；改了 `webui.py`（后端）要重启

## 环境要求

- macOS + **python3**（零第三方依赖，不需要 `pip install`）。实测**两个解释器都能跑**：
  - 双击 `查题.command` 走登录 shell → `/usr/local/bin/python3`（Python **3.14.7**，SQLite 3.53.4）
  - 终端里 `python3` 可能是 ServBay 的别名 → Python **3.9.22**（SQLite 3.40.0）
  - 两个版本上 `webui.py selftest` / `kb.py selftest` / `solve.py stats` 均通过
- **sqlite3 带 fts5 + trigram**（上面两个版本都带；自检：`python3 kb.py selftest`）
- `pdftotext`（poppler，实测 26.09.0，`/usr/local/bin/pdftotext`）—— 只在**从 PDF 教材抽文本**时用

## 页面能做什么

**查题 tab**
- 粘题干（带不带选项都行），`查询` 或 `Ctrl/⌘ + Enter`
- 上块：题库答案（大字号 + 题型·题号·命中率·来源·选项·解析）
- 下块：**官方原文依据**（材料类型 + 文件名 + 出处路径 + `[高亮]` 摘录）
- `联网兜底` 默认**关**：勾了才走联网检索（慢，且会写 `pending.jsonl`）

**刷题 tab**
- 选库 / 题型（单选·多选·判断）/ 题量（10/20/50/全部）→ `开始 / 重开`
- 逐题作答 → `提交` 立刻判 ✅/❌，给正确项 + 解析；多选题标「全对才算对」，答错还告诉你「漏选 BC / 错选 D」
- `看原文依据`：当场查这道题的官方原文（直连 kb 依据库）
- `跳过`：不会的题先跳过，不计入成绩；`结束并看结果`：本轮正确率 + 错题回顾
- **错题本**：答错的自动记住（存浏览器 localStorage），下次 `只练错题`；结果页可 `导出错题 txt`（含题号题型/全部选项/答案/解析，便于打印）
- **背题页（第三个页签，2026-09-22）**：问答体材料单独一页，逐条过 —— 先自己想 → `看答案` → `记住了` / `没记住`；没记住的进**待背清单**（localStorage `examcards:<材料>`，与错题本同源），下次可 `只背没记住的`。支持按章节筛、题量 10/20/50/全部、键盘 `空格`/`Enter` 看答案 · `1` 没记住 · `2` 记住了 · `→` 跳过、`导出这本问答 md`、待背清单 json 导出/导入（合并不覆盖）。后端只有两个只读接口 `/api/cardbooks`、`/api/cards?book=&chapter=`，真源就是 `crawl/*问答*.json`（`parse_handbook_qa.py` 的产物），**不复制第二份、也不进 banks/**。
  - 为什么不塞进刷题页：问答题没有选项，刷题页的判分/选项渲染套不上（塞进去只会得到一堆点不动的题）。所以单列一页，`webui.py selftest` 里也加了对应断言（数量与清单一致、题干答案非空、章节页码齐、按章筛选生效、路径穿越挡住）。
  - 现在这本材料是《网络和信息安全应知应会手册》**343 条**（第一章 108 / 第二章 85 / 第三章 35 / 第四章 110），导出 md 188 KB / 343 节，可直接打印或丢进 Obsidian。
- **网信安手册已落库**：kc「网络和信息安全」专区 4 本《应知应会手册》（第一~四章，pdftotext 共约 20 万字）进了语料库，`kb` 1006 → **1105 块**、619,060 → **695,382 字**；手册正文是问答体，`parse_handbook_qa.py` 把 **343 条官方问答**抽成背题表 `crawl/网信安-应知应会-问答.md`（+ 同名 .json，带手册内部页码）。**没有**塞进 banks/ 刷题库：问答题没有选项，刷题页的判分不适用（现在落在「背题」页签里，见上一条）。
  - 顺带修掉一个静默丢文件的坑：`kb.py` 的 `pdf_text()` 见到「PDF 旁边有同名 .txt」就 `return None`，但 `crawl/attach/**` 下没有任何 txt 通配在收 → 这对文件整对被丢。现在直接把旁边那份 txt 当文本源。

- **全库合计徽标行**：刷题页选库下拉上面那行 —— `全库 13 套 / 1296 题 ｜ 单选 670 ｜ 多选 260 ｜ 判断 366 ｜ 错题本 N 道`（D-058 起改成一排徽标，比一整句话好扫）。数据来自 `/api/banks`，前端求和（`showAllStat()`，挂在 `showBookInfo()` 那条刷新链上，错题本一变它跟着变）；`webui.py selftest` 里加了断言：**每个库的题型分布之和必须等于该库题数**，否则页面上这行会当场算错。
- **背题材料 4 份 / 1253 条（D-063）**：背题页的材料下拉由 `crawl/*问答*.json` 扫出来，现在有 —— 《网络和信息安全应知应会手册》343 条、**数字考点 221 条**（`crawl/数字考点-问答.json`：规章原文挖掉数字当问面，答面是完整原句 + 书名页码 + 「已考」标记）、**考点解析 22 条**（`crawl/考点解析-问答.json`：原文里的「X 是指…」「X 包括：…」）、**保密公开卷 667 道**（`crawl/保密公开题-问答.json`：题干+选项当问面，正确答案当答面）。生成脚本 `make_cards.py`（零依赖 + selftest）。为什么数字考点能 221 条而生成题只有 60 道：生成题要有选项，干扰项必须凑齐同单位 3 个真实数值；卡片不需要选项，所以同一批原文能全量背。444 条里剩下的是平台附件表格被抽断的碎片（「灭：动火范围 10 米内应具备 2 个 4 公斤灭火器，根」），宁缺勿错。
- **导入题目文件（D-063，用户点名要的）**：查题页 `导入题目文件…` —— 传「有题干、没答案」的文件（txt / md / csv / docx / pdf），逐题先查题库给答案、没命中的再给官方原文依据，结果表带徽标统计、可导出 txt / csv，未命中的还能「交给模型兜底」（逐题联网检索，上限 20 题，会写 pending.jsonl）。接口 `POST /api/import`（浏览器读成 base64 发过去，服务端零依赖解 docx/pdf）+ `POST /api/import_model`；切题按题号（`1.` / `2、`，编号须严格递增）或空行分段，单次上限 300 题，中文 txt 带 GB18030 兜底（微信/Word 导出的常不是 UTF-8）。
- **2026 年电信资料（D-063）**：技能认证专区页里 33 个 2026 条目筛出 9 个可采专题（服务投诉处理 / 智能客服 AI 训练师 / 政企客服专席 / AI 专业 / 数字生活 / 信创产数 / 天翼物联 / 视联网 / 基础设施开放共享），采到 **397 小节**，讲义文字 28.4 万字进了语料库（`kb` 3028 → **5494 块 / 240 万字**）。**没吃到**的是这批教材/大纲的「转换文字档」`_t.txt`（155 个直链 404，试过裸 fetch / 带 cookie / 带鉴权头 / `download?id=`），所以 2026 只有讲义文字 + 1 份 PDF。
- **清除按钮（D-062，用户点名要的）**：删完就忘的地方都给了清除，且都要二次确认（破坏性动作不摊在主操作旁边、也不一键就清）——
  - 查题页：`查询` 旁边的 `清除`（内联 SVG 垃圾桶图标，带 `aria-label`）→ 清空输入框 + 上次结果 + 状态行，光标回到输入框；网络兜底的勾选是设置不是内容，不跟着清。实测：输入 19 字 → 清后 0、结果区 263 字 → 0、`activeElement` = `q`。
  - 刷题页 `⋯ 导出／备份` 里：`清空本库错题本（不可撤）` —— 先报要清几道再问一句（「共 3 道，清掉不能恢复」），确认后 `localStorage.removeItem("examwrong:<库>")`，徽标与「错题本 N 道」当场跟着归零。
  - 背题页 `⋯ 导出／备份` 里：`清空待背清单（不可撤）` —— 同理，`examcards:<材料>` 清掉、待背徽标归零。
  - 验证脚本 `verify-clear.js` 全程走 `jr/tools/storage-guard.js` 快照 / 还原（清空操作本身就是改 localStorage，护栏不能省）。
- **整库导出（txt / md 两种）**：刷题页选好库 → `导出本库 txt` 或 `导出本库 md` —— 一次导出**整个库**（库名 + 题型分布 + 逐题题干/选项/答案/依据）：txt 便于打印，md 丢进 Obsidian / Notion / 语雀就是排版好的复习页；不受「题型/题量」下拉影响（那两个是练题用的），落地在浏览器下载目录 `题库-<库名>.txt|.md`。
  - **导出里不放任何溯源噪音**：题库内部记的「来源：…本人历史考试记录…｜这场得分 100.0，本题我答对了」「答案来源：试卷自带（未逐题核对官方原文）」这类段一律剥掉，**连表头那行「答案来源：」也不印**，只留「依据：《X法》第Y条：原文」；没依据的题到「答案：X」就结束。保密 2026 卷导出 14,424 → 11,484 字节、长期合集 36,435 → 31,210 字节。
    （两轮才干净：第一版只按「来源：」前缀丢段，漏了保密的第二段溯源「这场得分…」；`docs-*` 那几套用半角 `|` 分段，两种分隔符都要切。）
- **错题本可搬走**：`错题本导出 json` / `错题本导入 json` —— 把浏览器 localStorage 里所有库的错题本（`examwrong:<库名>`）打包成 `错题本-全部-YYYY-MM-DD.json`，换浏览器 / 换机器时导入（**与原有错题本合并，不覆盖**）。
- **保密公开题（D-062，真题目，不是生成题）**：`banks/保密公开题-中科院.json` —— `parse_pub_quiz.py` 把**机构自己发在官网上的公开测试卷**解析成题库：单文件 667 题（单选 349 / 多选 155 / 判断 163），答案按原卷自带，每题 `analysis` 里写清卷名。
  - 来源：中国科学院官网公开的《保密知识测试题及答案》（`imp.cas.cn`，原件存 `crawl/pub-lib/中科院-保密知识测试题.pdf`，pdftotext 转文本后解析）。
  - **收件规矩（写在这里免得下回放宽）**：只收机构 / 高校官网发布的成套测试题；**不碰**文库（renrendoc / book118 之类）里标题写着「某年线上培训考试题库」的转载件 —— 那是考卷泄露，不是公开资料。答案不自己判、不自己编，原卷写什么就是什么。
  - 解析要处理的坑：选项有三种排版（一行 `A 甲 B 乙 C 丙`／换行堆叠／折行把词劈开）；答案行会被分页符顶到行首（`…国家安全工\n作部门\n\f答案：A`），不许用 `^[ \t]*答案` 卡死，否则这条答案被吞进下一题、整题选项串位；判断题原卷只给「正确 / 错误」，转成 `A 正确 / B 错误`；PDF 折行处汉字之间的空格是排版残留，要并掉（拉丁字母间保留，如「U 盘」）。
  - 这个库带 `meta.external` + `meta.public`：**不进电信模拟考池、不进电信覆盖率分母**（实测 `kb_coverage.py` 输出里 0 次出现它），但在刷题页照常可刷、也进了查题索引。
  - 自检：`python3 parse_pub_quiz.py selftest` —— 题数 ≥600、题型分布、题干唯一、答案在选项内、选项不重复、选项里不许混进下一个选项字母，且已知两条必须对得上（第 1 题 = B、手机充电题 = 「错误」）。
- **生成题（明确标注，别跟真题混）**：`banks/自测-安全数字.json` —— 由 `make_drill.py` 把《管理办法》《规范》里带数字的规范句挖空（单选）或改数字（判断），干扰项只取**同单位的真实数值**，每题解析里带原文与出处，可逐条回查。刷题时题头会显示 `⚠ 生成题（依据见下，非真题）`。它不计入覆盖率统计（`meta.generated`）。现有 **60 题**（单选 30 / 判断 30），来源 `crawl/数字考点速查.csv`（441 条数字考点，其中 201 条题库已考）。几处讲究：
  - **出处写成人能翻到的位置**：句子来自《管理办法》正文或附件1 时写成 `《管理办法（试行）·附件1》安全防护用品配备 第24页`（只标到「一、」这一级 —— 往里精确定位到 `N．` 小标题会错，原文小节顺序与题目顺序无关）；其它仍是「书名 第N页」。
  - **解析里放整句原文**（不截断）：截断会把含数字的末句掐掉，答案就查不到了。
  - 类别从 6 类扩到 8 类（加 `个数`/`人`：「2 个灭火器」「不得两人同时上杆」也是硬规定），但这两类**必须有规范措辞**才收 —— 否则会把「同一人字梯」里的「一人」当成考点数量。
  - 两个防错：`每 12 个月` 被抽成 `12个` 时补回真正的单位（否则挖空成「每（　）月」而选项是「12个」）；量词后面被 PDF 断行截掉的（「…每 12 个」）直接丢。
- **保密教育真题（另一门考试，标了 external）**：按考试年份分库 —— `banks/baomi-2024.json`（中国保密在线 **你本人 2024 年两场「保密教育线上培训考试」的整卷**，去重后 **47 题**：单选 37 / 判断 10）与 `banks/baomi-2026.json`（**2026 年这场，20 题：单选 15 / 判断 5，你考了 100 分**），每题含官方正确答案和你当时的作答；另有 `banks/baomi-我的错题.json`（**17 题**，两场里答错的那批）。

## 新增一套题库（走通的 5 步）

1. 把试卷原文整份存成 `exam-lookup/<卷名>.txt`（**留档**，日后每个数字都能回原文复算）
2. 写/复用 `parse_<卷名>.py`（试卷原件）或 `parse_textbook_quiz.py`（教材小节测试，答案得从正文推）：切出「题号 / 选项 / 答案」→ 输出 `banks/<库名>.json`；
   末尾用断言把底线（题数、题型分布、题号连续、每题都有答案、单选选项数），对不上就 `exit 1`
3. `python3 solve.py build` —— 查题端立刻能搜到
4. `python3 sync_banks.py` —— 刷题端下拉里出现新库
5. `python3 webui.py selftest` —— 回归自检

参考实现：`parse_comm_safety.py`（通信安全生产 50 题：单选 20 + 判断 30）。

## 常见问题

- **端口被占 / 打不开**：双击方式会自动顺延 8765→8769；都被占就用 `python3 webui.py --port 9000`，然后开 `http://127.0.0.1:9000/`
- **双击和终端里的 python3 不是一个**：Finder 双击走登录 shell → `/usr/local/bin/python3`（3.14.7）；交互终端里可能是 ServBay 别名 → 3.9.22。两边都实测能跑；要统一就在 `查题.command` 里把 `python3` 写成绝对路径
- **「看原文依据」说没找到条文**：这是设计选择 —— 只用 ≥6 字长探针，**宁可缺、不给假依据**。
  实测通信安全 50 题里 **10/50** 能对到原文（口径：整题=题干+选项、探针 ≥6 字，`kb_coverage.py` 可复算），
  其余是通用安全常识，依据库里没有对应材料（要提覆盖率得往 kb 里补语料，不是调探针）
- **页面字太小**：右上角 `A+`（或 `⌘ +`）调大，会连按钮、下拉、选项一起缩放（全站 rem 由 `--fs` 驱动）
- **错题本不见了**：存在浏览器 localStorage（键名 `examwrong:<库文件名>`），换浏览器 / 清缓存会丢 —— 想留存就结果页 `导出错题 txt`
- **服务会不会一直开着**：不会。现在只是前台进程；要免手动可自行装 launchd（本项目**尚未**做）
- **`kb.sqlite3` / `qb.sqlite3` 能删吗**：能，都是索引 —— 前者 `python3 kb.py build`，后者 `python3 solve.py build` 重建
- **往依据库加材料**：把文件放进 `kb.py` 里 `SOURCES` 覆盖的路径（官方原件 / 教材 / 教材汇编 / 视频课件 / kc 平台抓的 `crawl/attach`、`crawl/subjects`），再 `python3 kb.py build`
- **「这是第几页」**：`python3 kb_pages.py index` 生成每本教材的章节→页码（**33 本 / 2031 页**，
  含《管理办法》《解读》两本命题主依据的 PDF —— 它们原先没纳入页码范围）；
  `python3 kb_pages.py map` 生成题库每道题最可能命中的教材页码（默认 48/366、通信安全 2/50）。
  注意：这个数比上一版（68/366）低，是**故意的保守** —— 页码语料从 1958 页涨到 2031 页后，
  「稀有窗(≤3 页)」判据变严，假命中跟着少；要放宽用 `python3 kb_pages.py map 1.0 1`。
- **「这个数字考过没」**：`python3 num_points.py` 抽出教材+规范里所有含数字的规范句
  （重量/长度/时间/周期/频次…**441 条**，其中 201 条的数字在题库里出现过），每条给**出处 + 页码 + 在题库里出现在哪些题**，
  产物 `crawl/数字考点速查.md|.csv`。安全卷失分大量在数字上（5kg / 2.5m / 30 分钟 / 3 年 / 1cm），
  背这张表比翻 30 本书快。
  加 `必背` 参数出**考前必背单**：`python3 num_points.py 必背` →
  `crawl/考前必背-综维安全数字.md`，按主题分桶（高处/上杆、有限空间、动火消防、电气安全、
  劳动防护、工器具、急救事故、交通道路、管理流程），带 ✓ 的是**安全类题库已经考过的数字**
  （命题人偏好），234 条里有 164 条带 ✓。
  页码是「关键词最集中的那页」，不等于条文页 —— 要原文仍以 `kb.py search` 的摘录为准；调 `map 1.5 1` 更准但命中更少
