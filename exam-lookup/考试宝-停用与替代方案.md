# 考试宝账号被停用：事实、归因与替代方案

2026-10-27 记录。**结论：对考试宝的自动化取数到此停止**，代码默认冻结，只保留离线部分。

## 一、事实

2026-10-27 在 9224 调试 Chrome 里打开 `https://www.kaoshibao.com/ti/17348551/` 时弹出：

    安全提示
    账号涉及违规操作，违反《用户服务协议》，账号已被停用。
    如有疑问，可通过【账号申诉】提交相关说明，我们将核实处理。

即账号被**平台停用**，不是本地脚本报错、不是 cookie 过期。同期抓包显示当时的登录态本身仍然有效
（token 64 位、uu 在、passphrase 在），说明这是账号维度的处置，发生在服务端。

## 二、归因（不宣称精确，只说证据能支持的部分）

- 平台是按**账号行为**判定的，判定看的是历史累计，不是某一次请求的快慢。
- 本仓库此前对账号做过的、与「个人查答案」明显不成比例的操作：
  - `/api/questions/lists` + `/api/questions/detail` 按整卷批量取题与答案（`kb_kaoshibao_api.py`）；
  - 免费搜题额度用尽（code 30001）后仍继续发起查询尝试；
  - 早期版本曾在半秒内并发 20 条请求（`call_many(batch=20)`，已删）。
- 2026-10-27 加的串行节流（1.2s + 抖动）只能降低**将来**被追加处罚的概率，不可能撤销已经作出的处置。
- 因此「再改一版更像人」不是解法：账号已经在这个服务上被打上标记，继续同一路线只会把下一个账号也搭进去。

## 三、代码现状（默认冻结，冷启动 agent 不会误触）

    python3 kb_kaoshibao_api.py pull      → 直接拒绝，退出码 5（提示本文件）
    python3 kb_answer_kaoshibao.py check|fetch → 同样拒绝，退出码 5
    python3 kb_kaoshibao_api.py selftest   → 仍可跑（离线假传输，只验节流/中止逻辑）
    python3 kb_answer_kaoshibao.py selftest/report/apply → 仍可跑（不联网）

解冻的唯一方式是在**账号状态恢复后**显式 `KSB_ALLOW=1`，并且只用官方额度内的量。

## 四、下一步（只走官方口径）

1. **先申诉**：点弹窗里的【账号申诉】，说明是个人备考核对用途、无二次分发或售卖、
   已停止脚本访问、请求恢复并要求按官方额度使用。申诉是唯一能让账号回来的路径。
2. **恢复后如仍要外部答案**：只走站点的官方「搜题」额度（VIP 10000 次/月），
   在网页里人工搜或用脚本在额度内搜，**不再批量取整卷**。额度内使用是平台卖的功能，越界不是。
3. **主链路不依赖它**：现有分层口径不变——本地专业文档能定的冻结不动；
   本地定不下来的进 `jr/out/no_local_evidence.md` 待人工核对；
   考试宝从「权威源」降级为「可选参考」，不再当作默认闭环的一环。
   人工核对已经排好队：`python3 kb_review_queue.py build` →
   `jr/out/review_queue.md`（1021 道，按「考场答错过 > 库存与推导冲突 > 核对成本」排序，
   先做「需比对」那 352 道）；缺哪些资料看 `python3 kb_review_queue.py materials`
   → `jr/out/missing_materials.md`。

## 五、数据现状（停用不影响）

- 题库 json、`jr/out/docs.sqlite`、`answers` 表都在本地，账号停用不丢任何已导出的数据。
- 已抓到的考试宝结论（`provenance='kaoshibao'` 的记录）继续有效，`report` / `apply` 都能离线跑。

## 六、申诉话术草稿（按实际情况删改后提交）

    您好，我的账号（用户名/绑定手机：____）今日登录时提示「涉及违规操作，账号已被停用」。
    我说明一下情况：本人是中国电信综维装维条线员工，用贵站核对内部安全生产与保密类考试的
    题库答案，纯个人备考使用，没有二次分发、售卖或对外提供数据。
    之前我用脚本访问过题库页面，频率上确实超出了正常人工浏览的范围，这是我的问题，
    相关脚本已经全部停用。恳请核实并恢复账号，恢复后我只在贵站官方额度内使用
    （需要的话我开通 VIP 额度），并保证不再用脚本批量访问。

要点：认下「频率超范围」这件事、说明用途、说明已停止、给出恢复后的承诺；不辩解、不讨价还价。
